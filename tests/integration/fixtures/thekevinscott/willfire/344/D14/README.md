`d14-dual-trigger.yml` triggers on `push: branches: [probe/d14-dual-trigger]` and bare `pull_request:`. Pushing the branch and opening the PR produced two `d14-dual` runs on the same head SHA — one per event. Only the `pull_request` run attaches to the PR; the `push` run is out per the recipe, though the PR's statusCheckRollup lists `d14-dual` twice. `prt-noop` (`pull_request_target`) is PR-attached and in.
